Пробник окружения

Этап 0 из ТЗ. Проверяет всё, от чего зависит выбор архитектуры. Запускать в том Chrome и на той машине, где пойдёт презентация.

0. Контекст запуска —

Открыт ли файл так, что браузер вообще пустит к микрофону. Если приложение планируется отдавать коллегам «двойным кликом по файлу», ответ здесь решает, возможно ли это.

1. Chrome Translator API —

Перевод на устройстве. Нужен режиму pin — быстрому и безлимитному. Каждую пару жать отдельно, скачивание пакета требует свежего клика. Региональные варианты португальского не различаем: аудитория смешанная, базового pt достаточно.

2. Web Speech API —

Распознавание для режима pin. Может быть отключено корпоративной политикой Chrome — это самый вероятный способ обрушить всю ветку. Скажите фразу на каждом языке.

ожидание

3. Системный звук —

Обратный канал. В диалоге Chrome выберите «Весь экран» и включите галочку «Также передать системный звук». Включите заранее любое видео со звуком, иначе индикатор останется на нуле.

—

4. Темп речи —

Сколько реплик вы производите в минуту. Умноженное на два часа, это число запросов к Gemini в режиме auto. Именно оно решает, жив ли auto на микрофоне вообще. Говорите как на презентации — 60 секунд.

—

5. Gemini: задержка и определение языка —

Ключ никуда не отправляется, кроме самого Google, и не сохраняется. Скажите одну фразу на любом языке — замеряется время от конца речи до готового JSON и проверяется, верно ли определён язык.
